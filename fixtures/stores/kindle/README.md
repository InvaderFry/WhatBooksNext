# Invented Kindle library answers

These copy the structure of the Kindle web library's search answer
(`read.amazon.com/kindle-library/search`) as publicly described. Every title, author and ID is
invented: the IDs start with `INVENTED`, which isn't Amazon's ASIN form, so none can point to a
real book. They prove the collector's logic, not that it works on the live store; owner action A2
checks that. Replace the structure (never with real titles) once the owner's report shows a
difference.
