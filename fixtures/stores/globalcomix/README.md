# Invented GlobalComix purchases answers

These copy the structure of `api.globalcomix.com/v1/account/digital-purchases?p=N` as the owner's
look-around report showed it (2026-11-11; field names only, trimmed to the fields the collector
reads, with a few others kept so the layout looks real). Every title, series, ISBN and ID is
invented, and the IDs start at 9100000, so none is meant to point to a real comic.
